FX Command Center Manual

EAの状態を見て、履歴を読み込み、仮説を検証して、次の判断材料をつくるためのローカル分析ハブです。

01 / GET STARTED

はじめに

ダッシュボードはサンプルデータですぐ試せます。左のナビゲーションから、確認したいワークスペースへ移動してください。画面上部の ↻ はデモデータへのリセット、◌ は Hub manifest の確認です。

おすすめの順番
CSVインポート → EA分析 → EA Health → Risk Console → AIプロンプト

02 / DATA INGEST

CSVを取り込む

CSVインポート画面でMT4 / MT5の取引履歴をドロップするか、ファイルを選択します。ヘッダーは Time / Expert / Symbol / Type / Volume / Profit などを自動認識します。

  1. MT4 / MT5の口座履歴を表示し、対象期間を保存します。
  2. CSVインポート画面へファイルをドロップします。
  3. 読み込み成功後、自動的にEA分析画面へ移動します。

10MBまで。UTF-8を推奨します。サンプルCSVのダウンロードも可能です。

03 / OBSERVE

EA分析とEA Health

EA分析ではEAごとのNet P/L、Return、Max DD、勝率、取引数をカードで比較できます。フィルターの「稼働中」「要確認」で優先順位を絞れます。

EA Healthは、ステータス、稼働率、ハートビート、直近損益を一覧化します。Watchは停止を意味せず、DDや約定遅延など確認を推奨する状態です。

04 / WHAT-IF

LabとRisk Console

Labではロット倍率、勝率変化、スプレッド変化、期間を動かし、期待損益・想定DD・Sharpeの方向感を確認します。これは簡易シナリオであり、約定条件や相関を完全に再現するものではありません。

Risk Consoleでは、口座残高・リスク率・SL距離・通貨ペアのpip valueからロットサイズを計算します。

推奨ロット = 口座残高 × リスク率 ÷（SL pips × 1 lotあたりのpip value）

05 / AI ASSIST

AIプロンプトを生成する

相談テーマを選ぶと、現在のポートフォリオ指標と直近取引を含む日本語プロンプトが生成されます。追加コンテキストを入力してからコピーし、利用中のAIへ貼り付けてください。

AIの出力は投資判断そのものではありません。数値の出典、期間、取引コストを確認した上で利用してください。

06 / DATA POLICY

データと注意事項

このMVPはサーバーを持たない静的アプリです。CSVはブラウザのメモリとlocalStorageにのみ保存され、外部へ自動送信されません。ブラウザのサイトデータを消去すると読み込み済みデータも消えます。

FX・CFD取引には元本割れのリスクがあります。表示値は分析補助のための参考値であり、利益を保証するものではありません。
