# FX Command Center Decisions

## 2026-09-07 — Astra–Sol governance
Status: Adopted for repository governance

Astra is Chief Architect for root data/risk/execution architecture; Sol is Main Operator; Codex implements approved changes.

## Existing decision — Static analysis MVP
Status: Maintain

The current product is a browser-based analysis/support tool with local CSV import and local persistence.

## Existing decision — No profit guarantee
Status: Maintain

Historical/backtest/analysis values are informational and do not guarantee future performance.

## Existing decision — Deterministic risk calculations
Status: Maintain

Risk/lot calculations should remain explicit, reproducible and separate from free-form AI interpretation.

## Existing decision — Analysis vs execution
Status: Maintain

The current product does not autonomously place trades or store brokerage credentials.

## Expansion direction — Macro/fundamental FX intelligence
Status: Maintain

USD/JPY and other currency analysis may incorporate rates, central-bank policy, inflation, employment, GDP, geopolitics and sentiment while preserving source provenance/freshness.

## Change control
Classify major proposals Maintain / Modify / Retire / Hold. Major architecture changes require explicit user acceptance.
